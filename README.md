# **Image Generation Using Stable Diffusion & Comfy UI**  

![Stable Diffusion Image](https://via.placeholder.com/800x400.png?text=AI+Generated+Image)  

## **📌 Project Overview**  
This repository contains AI-generated images created using **Stable Diffusion** and **Comfy UI** as part of the **AICTE Internship on AI: Transformative Learning with TechSaksham (Microsoft & SAP)**.  

The project explores the capabilities of **text-to-image generation**, optimizing model parameters, and experimenting with **negative prompts, sampling techniques, and node-based workflows** to enhance output quality.
